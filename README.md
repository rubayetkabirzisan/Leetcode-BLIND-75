## 💡 Approach & Philosophy

Every solution in this repository follows a consistent problem-solving philosophy:

**1. Understand Before Coding**
Before writing a single line, the problem is broken down into its core constraints — what input is given, what output is expected, and what edge cases exist.

**2. Brute Force → Optimized**
Solutions start with the simplest possible approach, then are refined using pattern recognition (e.g., sliding window, two pointers, hash maps) to achieve the optimal time and space complexity.

**3. Clarity Over Cleverness**
Code is written to be readable. Variable names are meaningful, logic is straightforward, and solutions are structured so they can be revisited and understood at a glance — not just submitted and forgotten.

**4. Python Idioms**
Solutions take advantage of Python's built-in data structures (`dict`, `set`, `deque`) and language features to write concise, efficient code.

## 📊 Example: Approach Breakdown

### Two Sum — O(n) Time, O(n) Space
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        prevMap = {}                        # val → index

        for i, n in enumerate(nums):
            diff = target - n
            if diff in prevMap:             # complement already seen
                return [prevMap[diff], i]
            prevMap[n] = i                  # store current value
```
> **Key Insight:** Instead of a nested O(n²) loop, a hash map lets us check for the complement of each number in O(1), reducing the overall complexity to a single pass.
